# WEDE5020-PART-2
## Website Projects
This repository contains two website projects developed for the Web Development Part Two project.
The two websites are:
1. Palesa's Hair Studio
2. Celebrate With Us
Both websites were created using HTML5 and CSS3. External CSS was used to style the pages and responsive design was added so that the websites can work on different screen sizes.
# 1. PALESA'S HAIR STUDIO
## About the Website
Palesa's Hair Studio is a hair and beauty website created to provide customers with information about the salon and the services offered.
The website allows users to view different hairstyles, learn more about the salon, find contact information and make enquiries.
## Website Pages
The website contains the following pages:
- Home
- About Us
- Services
- Contact
- Enquiries
## Services
The Services page includes:
- Braiding
- Weaves
- Wig Installation
- Hair Washing & Treatment
- Natural Hair Styling
- Hair Colouring
- Cornrows
- Haircuts
## Technologies Used
- HTML5
- CSS3
- External CSS
- CSS Media Queries
- Visual Studio Code
- Google Chrome
- GitHub
## Responsive Design
The website was designed to work on different screen sizes.
CSS media queries were used to adjust the layout for:
- Desktop
- Tablet
- Mobile
The navigation, images, service sections, text and enquiry form were adjusted to make the website easier to use on smaller screens.

# 4. TESTING AND ITERATION
The websites were continuously tested during development to make sure that the pages worked correctly.
During testing, the following were checked:
- Navigation links
- Images
- Text
- Page layout
- Buttons
- Enquiry forms
- Responsive design
- Different screen sizes
After testing, CSS adjustments were made where necessary to improve the layout and user experience.
The websites were tested again after the changes to make sure that the design remained clear and easy to use.
# 5. DESIGN PRINCIPLES
## Prioritise Content
The important information was placed where users can easily see it. The websites focus on the main services and information instead of unnecessary content.
## Keep It Simple
The websites use simple layouts, clear navigation and readable text. This makes it easier for users to find the information they need.
## Test Thoroughly
Both websites were tested on desktop, tablet and mobile screen sizes. The pages were checked to make sure that the content and layout work correctly.
## Stay Up-to-Date
Modern CSS techniques such as responsive layouts, CSS Grid, media queries and relative units were used to improve the websites and make them suitable for different devices.
